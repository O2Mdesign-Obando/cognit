# Cognit Learning Hub extraction boundary

The Cognit Learning Hub Demo was extracted as a product surface, not cloned from its source repository.

## Retained

- Cognit brand assets required by the demo
- A neutral Astro layout, header, footer, and container
- Five demo perspectives and their deep routes
- The shared synthetic demo model, images, routes, and browser-local interactions
- Center operating contexts for Northfield Studio and Harbor Academy Program
- Center-to-Student/Family synthetic publication continuity
- Responsive and accessible demo semantics present in the qualified surface

## Replaced

The source layout and global styles were replaced with a purpose-built Cognit shell because the originals carried unrelated Pilot and CodeWiz responsibilities. Only the neutral presentation responsibility was retained.

## Excluded

- Supabase clients, configuration, migrations, and data loaders
- Production authorization, tenancy, middleware, and environment bindings
- CodeWiz Pilot configuration, credentials, data, branding, and release automation
- Northstar records and fixtures
- Unrelated curriculum, reports, documentation, generated output, caches, and Vercel project metadata
- Real payment, email, support, AI, migration, media upload, or camera integrations

## Canonical route

The demo is canonical beneath `/learninghub/demo`. No production domain is configured by this repository.
